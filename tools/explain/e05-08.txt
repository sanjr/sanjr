5-1	Ctrl + C copies the selected text or object in every office suite, including OpenOffice.	Ctrl + C हर ऑफिस सूट (OpenOffice सहित) में चयनित टेक्स्ट या ऑब्जेक्ट कॉपी करता है।	Ctrl + C प्रत्येक ऑफिस सूटमध्ये (OpenOffice सह) निवडलेला मजकूर किंवा ऑब्जेक्ट कॉपी करते.
5-2	Ctrl + E centres the text; Ctrl + L = left, Ctrl + R = right, Ctrl + J = justify.	Ctrl + E टेक्स्ट को सेंटर करता है; Ctrl + L बाएँ, Ctrl + R दाएँ, Ctrl + J जस्टिफाई।	Ctrl + E मजकूर मध्यभागी आणते; Ctrl + L डावीकडे, Ctrl + R उजवीकडे, Ctrl + J जस्टिफाय.
5-3	An audio file is embedded in Word through Insert → Object.	Word में ऑडियो फाइल Insert → Object के द्वारा जोड़ी जाती है।	Word मध्ये ऑडिओ फाइल Insert → Object द्वारे जोडली जाते.
5-4	In OpenOffice, Shift + Ctrl + N opens the Templates and Documents dialog.	OpenOffice में Shift + Ctrl + N टेम्पलेट्स और डॉक्यूमेंट्स डायलॉग खोलता है।	OpenOffice मध्ये Shift + Ctrl + N टेम्प्लेट्स आणि डॉक्युमेंट्स डायलॉग उघडते.
5-5	The data source holds the list of names/addresses; one copy is made for each record.	डेटा सोर्स में नाम/पतों की सूची होती है; हर रिकॉर्ड के लिए एक प्रति बनती है।	डेटा सोर्समध्ये नावे/पत्त्यांची यादी असते; प्रत्येक रेकॉर्डसाठी एक प्रत तयार होते.
5-6	A cover page is the first page where you fill the title, author and date.	कवर पेज पहला पेज है जिसमें शीर्षक, लेखक और दिनांक भरते हैं।	कव्हर पेज हे पहिले पान असून त्यात शीर्षक, लेखक आणि तारीख भरतात.
5-7	Ctrl + Tab inserts a tab inside a header/table where plain Tab moves the cursor.	Ctrl + Tab हेडर/टेबल में टैब डालता है, जहाँ सामान्य Tab कर्सर को आगे ले जाता है।	Ctrl + Tab हेडर/टेबलमध्ये टॅब घालते, जिथे साधा Tab कर्सर पुढे नेतो.
5-8	The Quick Access Toolbar keeps frequently used commands like Save, Undo and Redo.	क्विक एक्सेस टूलबार में Save, Undo, Redo जैसे बार-बार उपयोग के कमांड रहते हैं।	क्विक ॲक्सेस टूलबारमध्ये Save, Undo, Redo सारख्या वारंवार वापरल्या जाणाऱ्या कमांड असतात.
5-9	Save (Ctrl + S) stores the active document permanently on the disk.	Save (Ctrl + S) सक्रिय डॉक्यूमेंट को डिस्क पर स्थायी रूप से सेव करता है।	Save (Ctrl + S) सक्रिय डॉक्युमेंट डिस्कवर कायमस्वरूपी सेव्ह करते.
5-10	=SUM() adds the numbers of a row or column in a table.	=SUM() टेबल की पंक्ति या कॉलम की संख्याओं को जोड़ता है।	=SUM() टेबलमधील ओळ किंवा कॉलममधील संख्यांची बेरीज करते.
5-11	The title bar at the top shows the name of the open document.	सबसे ऊपर का टाइटल बार खुले डॉक्यूमेंट का नाम दिखाता है।	सर्वात वरचा टायटल बार उघडलेल्या डॉक्युमेंटचे नाव दाखवतो.
5-12	Gutter margin adds extra space on the binding side so text is not hidden after binding.	गटर मार्जिन बाइंडिंग वाली तरफ़ अतिरिक्त जगह देता है ताकि टेक्स्ट न छिपे।	गटर मार्जिन बाइंडिंगच्या बाजूला जास्त जागा देते, म्हणजे मजकूर लपत नाही.
5-13	Tab stops are set by clicking on the horizontal ruler.	टैब स्टॉप हॉरिजॉन्टल रूलर पर क्लिक करके सेट होते हैं।	टॅब स्टॉप हॉरिझॉन्टल रूलरवर क्लिक करून सेट होतात.
5-14	Each box formed by a row and a column in a table is called a cell.	टेबल में पंक्ति और कॉलम से बना हर बॉक्स सेल कहलाता है।	टेबलमध्ये ओळ आणि कॉलम मिळून तयार होणाऱ्या प्रत्येक चौकटीला सेल म्हणतात.
5-15	Mail merge combines names and addresses from a list into a standard letter.	मेल मर्ज सूची के नाम और पते एक मानक पत्र में जोड़ता है।	मेल मर्ज यादीतील नावे आणि पत्ते एका स्टँडर्ड पत्रात एकत्र करते.
5-16	The status bar at the bottom shows page number, word count and cursor position.	नीचे का स्टेटस बार पेज नंबर, शब्द संख्या और कर्सर की स्थिति दिखाता है।	खालचा स्टेटस बार पेज नंबर, शब्दसंख्या आणि कर्सरची स्थिती दाखवतो.
5-17	Letters is the default document type when you start a mail merge.	मेल मर्ज शुरू करने पर डिफ़ॉल्ट डॉक्यूमेंट प्रकार Letters होता है।	मेल मर्ज सुरू केल्यावर डीफॉल्ट डॉक्युमेंट प्रकार Letters असतो.
5-18	Merging joins two or more cells into one single cell.	मर्जिंग दो या अधिक सेल को एक सेल में जोड़ देता है।	मर्जिंग दोन किंवा अधिक सेल एका सेलमध्ये एकत्र करते.
5-19	Before finishing, you preview the merge results to check each letter.	पूरा करने से पहले हर पत्र जाँचने के लिए मर्ज परिणामों का पूर्वावलोकन करते हैं।	पूर्ण करण्यापूर्वी प्रत्येक पत्र तपासण्यासाठी मर्ज निकालांचा प्रिव्ह्यू करतात.
5-20	Ctrl + P opens the Print dialog.	Ctrl + P प्रिंट डायलॉग खोलता है।	Ctrl + P प्रिंट डायलॉग उघडते.
5-21	AutoCorrect automatically fixes common typing mistakes as you type.	ऑटोकरेक्ट टाइप करते समय सामान्य गलतियाँ अपने आप सुधारता है।	ऑटोकरेक्ट टाइप करताना सामान्य चुका आपोआप दुरुस्त करते.
5-22	Web Layout view shows the document as it would look in a web browser.	वेब लेआउट व्यू डॉक्यूमेंट को वेब ब्राउज़र जैसा दिखाता है।	वेब लेआउट व्ह्यू डॉक्युमेंट वेब ब्राउझरमध्ये दिसेल तसे दाखवतो.
5-23	All mail merge commands are in the Mailings tab.	मेल मर्ज के सभी कमांड Mailings टैब में होते हैं।	मेल मर्जच्या सर्व कमांड Mailings टॅबमध्ये असतात.
5-24	Scale lets you print the document at a different proportional size (e.g. fit A4 on A5).	स्केल से डॉक्यूमेंट को अलग आनुपातिक आकार में प्रिंट कर सकते हैं (जैसे A4 को A5 पर)।	स्केलमुळे डॉक्युमेंट वेगळ्या प्रमाणबद्ध आकारात प्रिंट करता येते (उदा. A4 ते A5).
5-25	WordArt creates decorative styled text with shadows, outlines and effects.	वर्डआर्ट शैडो, आउटलाइन और इफ़ेक्ट वाला सजावटी टेक्स्ट बनाता है।	वर्डआर्ट शॅडो, आउटलाइन आणि इफेक्टसह सजावटी मजकूर तयार करते.
6-1	Values separated by commas, one record per line, form a CSV (Comma Separated Values) file.	कॉमा से अलग किए मान, हर पंक्ति में एक रिकॉर्ड – यह CSV (Comma Separated Values) फाइल है।	स्वल्पविरामाने वेगळी केलेली मूल्ये, प्रत्येक ओळीत एक रेकॉर्ड – ही CSV (Comma Separated Values) फाइल आहे.
6-2	Filter shows only the rows that match your condition and hides the rest.	फ़िल्टर केवल शर्त से मेल खाने वाली पंक्तियाँ दिखाता है और बाकी छिपा देता है।	फिल्टर फक्त अटीशी जुळणाऱ्या ओळी दाखवतो आणि बाकीच्या लपवतो.
6-3	The Data tab has Get Data (import), Group/Outline and Subtotal commands.	Data टैब में Get Data (इम्पोर्ट), Group/Outline और Subtotal कमांड हैं।	Data टॅबमध्ये Get Data (इम्पोर्ट), Group/Outline आणि Subtotal कमांड असतात.
6-4	The PivotTable field list has boxes: Filters, Column Labels, Row Labels and Values.	PivotTable फ़ील्ड सूची में बॉक्स होते हैं: Filters, Column Labels, Row Labels और Values।	PivotTable फील्ड लिस्टमध्ये बॉक्स असतात: Filters, Column Labels, Row Labels आणि Values.
6-5	Page Layout → Scale to Fit → Width = 1 page fits all columns on one page.	Page Layout → Scale to Fit → Width = 1 page सभी कॉलम एक पेज पर फिट कर देता है।	Page Layout → Scale to Fit → Width = 1 page सर्व कॉलम एका पेजवर बसवते.
6-6	Every formula in Excel begins with the = sign, e.g. =A1+B1.	Excel में हर सूत्र = चिह्न से शुरू होता है, जैसे =A1+B1।	Excel मध्ये प्रत्येक सूत्र = चिन्हाने सुरू होते, उदा. =A1+B1.
6-7	Goal Seek finds the input value needed to get a desired result for one variable.	गोल सीक एक वेरिएबल के लिए वांछित परिणाम पाने हेतु आवश्यक इनपुट मान खोजता है।	गोल सीक एका व्हेरिएबलसाठी हवा तो निकाल मिळवण्यासाठी आवश्यक इनपुट मूल्य शोधतो.
6-8	Data Validation (Data tab of MS Excel) restricts what can be typed in a cell.	डेटा वैलिडेशन (MS Excel का Data टैब) सेल में डाले जा सकने वाले मान सीमित करता है।	डेटा व्हॅलिडेशन (MS Excel चा Data टॅब) सेलमध्ये काय टाइप करता येईल ते मर्यादित करते.
6-9	Ctrl + T converts the selected range into a table via the Create Table dialog.	Ctrl + T क्रिएट टेबल डायलॉग द्वारा चयनित रेंज को टेबल में बदलता है।	Ctrl + T क्रिएट टेबल डायलॉगद्वारे निवडलेली रेंज टेबलमध्ये बदलते.
6-10	Bubble chart is an Excel chart type that shows three values (X, Y and bubble size).	बबल चार्ट Excel का चार्ट प्रकार है जो तीन मान (X, Y और बबल आकार) दिखाता है।	बबल चार्ट हा Excel चा चार्ट प्रकार असून तो तीन मूल्ये (X, Y आणि बबल आकार) दाखवतो.
6-11	Page Layout view shows pages, margins, headers and footers exactly as printed.	पेज लेआउट व्यू पेज, मार्जिन, हेडर-फुटर ठीक वैसे दिखाता है जैसे प्रिंट होंगे।	पेज लेआउट व्ह्यू पेजेस, मार्जिन, हेडर-फूटर प्रिंट होतील तसेच दाखवतो.
6-12	The Page Setup group (margins, orientation, size) is on the Page Layout / Layout tab.	पेज सेटअप ग्रुप (मार्जिन, ओरिएंटेशन, साइज़) Page Layout / Layout टैब पर होता है।	पेज सेटअप ग्रुप (मार्जिन, ओरिएंटेशन, साइज) Page Layout / Layout टॅबवर असतो.
6-13	Sort rearranges rows based on the values of a chosen column.	सॉर्ट चुने गए कॉलम के मानों के आधार पर पंक्तियों को व्यवस्थित करता है।	सॉर्ट निवडलेल्या कॉलमच्या मूल्यांनुसार ओळींची मांडणी बदलते.
6-14	A macro shortcut is Ctrl + a letter (alphabetic key), e.g. Ctrl + M.	मैक्रो शॉर्टकट Ctrl + एक अक्षर (अल्फाबेटिक की) होता है, जैसे Ctrl + M।	मॅक्रो शॉर्टकट Ctrl + एक अक्षर (अल्फाबेटिक की) असतो, उदा. Ctrl + M.
6-15	View tab → Show group → tick Formula Bar to display it again.	View टैब → Show ग्रुप → Formula Bar पर टिक करके उसे फिर दिखाएँ।	View टॅब → Show ग्रुप → Formula Bar वर टिक करून तो पुन्हा दाखवा.
6-16	Excel 2007 onwards has 1,048,576 rows and 16,384 columns (XFD).	Excel 2007 से आगे 1,048,576 पंक्तियाँ और 16,384 कॉलम (XFD) होते हैं।	Excel 2007 पासून 1,048,576 ओळी आणि 16,384 कॉलम (XFD) असतात.
6-17	Sorting arranges data in ascending (A–Z) or descending (Z–A) order.	सॉर्टिंग डेटा को आरोही (A–Z) या अवरोही (Z–A) क्रम में लगाता है।	सॉर्टिंग डेटा चढत्या (A–Z) किंवा उतरत्या (Z–A) क्रमाने लावते.
6-18	F12 opens the Save As dialog box in Office programs.	ऑफिस प्रोग्राम में F12 सेव ऐज़ डायलॉग बॉक्स खोलता है।	ऑफिस प्रोग्राममध्ये F12 सेव्ह ॲज डायलॉग बॉक्स उघडते.
6-19	The Insert tab adds PivotTables, charts, pictures and hyperlinks.	Insert टैब PivotTable, चार्ट, चित्र और हाइपरलिंक जोड़ता है।	Insert टॅब PivotTable, चार्ट, चित्रे आणि हायपरलिंक जोडतो.
6-20	Select the data, then use Insert tab → Charts group.	डेटा चुनें, फिर Insert टैब → Charts ग्रुप का उपयोग करें।	डेटा निवडा, नंतर Insert टॅब → Charts ग्रुप वापरा.
6-21	A PivotTable is inserted from Insert tab → Tables group → PivotTable.	PivotTable को Insert टैब → Tables ग्रुप → PivotTable से इन्सर्ट करते हैं।	PivotTable हे Insert टॅब → Tables ग्रुप → PivotTable मधून इन्सर्ट करतात.
6-22	A pie chart shows each part as a slice (percentage) of the whole.	पाई चार्ट हर भाग को पूरे के एक टुकड़े (प्रतिशत) के रूप में दिखाता है।	पाई चार्ट प्रत्येक भाग संपूर्णाचा एक तुकडा (टक्केवारी) म्हणून दाखवतो.

6-24	COUNT() counts cells that contain numbers; COUNTA counts non-empty cells.	COUNT() संख्याओं वाले सेल गिनता है; COUNTA खाली न होने वाले सेल गिनता है।	COUNT() संख्या असलेले सेल मोजते; COUNTA रिकामे नसलेले सेल मोजते.

7-11	PowerPoint is presentation graphics software used to make slide shows.	PowerPoint प्रेजेंटेशन ग्राफिक्स सॉफ्टवेयर है जिससे स्लाइड शो बनते हैं।	PowerPoint हे प्रेझेंटेशन ग्राफिक्स सॉफ्टवेअर असून त्याने स्लाइड शो बनवतात.
7-12	Home → New Slide → Reuse Slides lets you insert slides from another presentation.	Home → New Slide → Reuse Slides से दूसरी प्रेजेंटेशन की स्लाइड्स जोड़ सकते हैं।	Home → New Slide → Reuse Slides मधून दुसऱ्या प्रेझेंटेशनच्या स्लाइड्स जोडता येतात.
7-13	The Animations tab applies entrance, emphasis and exit effects to text and objects.	Animations टैब टेक्स्ट और ऑब्जेक्ट पर एंट्रेंस, एम्फेसिस और एग्ज़िट इफ़ेक्ट लगाता है।	Animations टॅब मजकूर व ऑब्जेक्टवर एन्ट्रन्स, एम्फसिस आणि एक्झिट इफेक्ट लावतो.

7-15	PowerPoint 2007 and later save presentations as .pptx.	PowerPoint 2007 और बाद के संस्करण प्रेजेंटेशन .pptx में सेव करते हैं।	PowerPoint 2007 आणि नंतरच्या आवृत्त्या प्रेझेंटेशन .pptx मध्ये सेव्ह करतात.
7-16	OpenOffice Impress is the presentation program (like PowerPoint).	OpenOffice Impress प्रेजेंटेशन प्रोग्राम है (PowerPoint जैसा)।	OpenOffice Impress हा प्रेझेंटेशन प्रोग्राम आहे (PowerPoint सारखा).
7-17	Themes (colours, fonts, backgrounds) are in the Design tab.	थीम्स (रंग, फॉन्ट, बैकग्राउंड) Design टैब में होती हैं।	थीम्स (रंग, फॉन्ट, बॅकग्राउंड) Design टॅबमध्ये असतात.
7-18	Action buttons add ready-made interactive buttons (next, back, home) to slides.	एक्शन बटन स्लाइड पर तैयार इंटरैक्टिव बटन (next, back, home) जोड़ते हैं।	ॲक्शन बटणे स्लाइडवर तयार इंटरॲक्टिव्ह बटणे (next, back, home) जोडतात.
7-19	Slide Transition timing advances slides automatically after a set time.	स्लाइड ट्रांज़िशन टाइमिंग तय समय के बाद स्लाइड अपने आप आगे बढ़ाती है।	स्लाइड ट्रान्झिशन टायमिंग ठराविक वेळेनंतर स्लाइड आपोआप पुढे नेते.
7-20	Dotted boxes on a new slide are placeholders for title, text and other content.	नई स्लाइड के बिंदीदार बॉक्स टाइटल, टेक्स्ट आदि के प्लेसहोल्डर होते हैं।	नव्या स्लाइडवरील ठिपकेदार चौकटी शीर्षक, मजकूर इत्यादींचे प्लेसहोल्डर्स असतात.
8-1	A SQL function must declare what it returns – 'returns integer' is missing.	SQL फंक्शन को बताना होता है कि वह क्या लौटाएगा – 'returns integer' गायब है।	SQL फंक्शनने काय परत करणार ते सांगावे लागते – 'returns integer' नाही.
8-2	The recovery system restores the database after failures, ensuring durability.	रिकवरी सिस्टम विफलता के बाद डेटाबेस बहाल कर ड्यूरेबिलिटी सुनिश्चित करती है।	रिकव्हरी सिस्टम बिघाडानंतर डेटाबेस पूर्ववत करून ड्युरेबिलिटी सुनिश्चित करते.
8-3	DDL = Data Definition Language (CREATE, ALTER, DROP, TRUNCATE).	DDL = डेटा डेफिनिशन लैंग्वेज (CREATE, ALTER, DROP, TRUNCATE)।	DDL = डेटा डेफिनिशन लँग्वेज (CREATE, ALTER, DROP, TRUNCATE).
8-4	DROP TABLE removes the whole table – its structure and all its data.	DROP TABLE पूरी टेबल – उसकी संरचना और सारा डेटा – हटा देता है।	DROP TABLE संपूर्ण टेबल – त्याची रचना आणि सर्व डेटा – काढून टाकते.
8-5	DDL commands create, delete and alter database objects such as tables.	DDL कमांड टेबल जैसे डेटाबेस ऑब्जेक्ट बनाते, हटाते और बदलते हैं।	DDL कमांड टेबलसारखे डेटाबेस ऑब्जेक्ट तयार करतात, काढतात आणि बदलतात.
8-6	IN parameters pass values into a procedure and OUT parameters return results.	IN पैरामीटर प्रोसीजर में मान भेजते हैं और OUT पैरामीटर परिणाम लौटाते हैं।	IN पॅरामीटर प्रोसिजरमध्ये मूल्ये पाठवतात आणि OUT पॅरामीटर निकाल परत करतात.
8-7	Concurrency control manages transactions running at the same time so data stays correct.	कॉन्करेंसी कंट्रोल एक साथ चल रहे ट्रांज़ैक्शन को नियंत्रित करता है ताकि डेटा सही रहे।	कॉन्करन्सी कंट्रोल एकाच वेळी चालणारे ट्रान्झॅक्शन्स नियंत्रित करते, त्यामुळे डेटा बरोबर राहतो.
8-8	A transaction is a group of operations treated as one logical unit – all or none.	ट्रांज़ैक्शन ऑपरेशन्स का समूह है जो एक तार्किक इकाई माना जाता है – या तो सब या कुछ नहीं।	ट्रान्झॅक्शन म्हणजे एक लॉजिकल युनिट मानला जाणारा ऑपरेशन्सचा गट – एकतर सर्व किंवा काहीच नाही.
8-9	Atomic means the value cannot be divided further – an indivisible unit.	एटॉमिक का अर्थ है मान को और विभाजित नहीं किया जा सकता – अविभाज्य इकाई।	ॲटॉमिक म्हणजे मूल्याचे आणखी भाग करता येत नाहीत – अविभाज्य युनिट.
8-10	The domain of an attribute is the set of all values it is allowed to take.	किसी एट्रिब्यूट का डोमेन उसके सभी अनुमत मानों का समूह है।	ॲट्रिब्यूटचे डोमेन म्हणजे त्याला परवानगी असलेल्या सर्व मूल्यांचा संच.
8-11	To query a view, the user needs SELECT privilege on that view.	व्यू पर क्वेरी चलाने के लिए उस व्यू पर SELECT विशेषाधिकार चाहिए।	व्ह्यूवर क्वेरी चालवण्यासाठी त्या व्ह्यूवर SELECT प्रिव्हिलेज लागतो.
8-12	DECLARE … HANDLER defines what to do when an error/condition occurs – exception handling.	DECLARE … HANDLER बताता है कि त्रुटि/स्थिति आने पर क्या करें – एक्सेप्शन हैंडलिंग।	DECLARE … HANDLER त्रुटी/स्थिती आल्यावर काय करायचे ते ठरवतो – एक्सेप्शन हँडलिंग.
8-13	DML = Data Manipulation Language (SELECT, INSERT, UPDATE, DELETE).	DML = डेटा मैनिपुलेशन लैंग्वेज (SELECT, INSERT, UPDATE, DELETE)।	DML = डेटा मॅनिप्युलेशन लँग्वेज (SELECT, INSERT, UPDATE, DELETE).
8-14	A relational database stores data in related tables of rows and columns (e.g. MySQL).	रिलेशनल डेटाबेस डेटा को पंक्ति-कॉलम वाली संबंधित टेबलों में रखता है (जैसे MySQL)।	रिलेशनल डेटाबेस डेटा ओळी-कॉलमच्या संबंधित टेबल्समध्ये साठवतो (उदा. MySQL).
8-15	Compound statements are written as begin … end, or begin atomic … end.	कंपाउंड स्टेटमेंट begin … end या begin atomic … end के रूप में लिखे जाते हैं।	कंपाउंड स्टेटमेंट begin … end किंवा begin atomic … end असे लिहिले जातात.
8-16	A crosstab query calculates sum/average and groups results by two sets of values (rows × columns).	क्रॉसटैब क्वेरी योग/औसत निकालकर परिणाम को दो सेट (पंक्ति × कॉलम) में समूहित करती है।	क्रॉसटॅब क्वेरी बेरीज/सरासरी काढून निकाल दोन संचांनुसार (ओळ × कॉलम) गटबद्ध करते.
8-17	As per the question bank, consistency keeps the database correct when a transaction runs alone.	प्रश्न बैंक के अनुसार, ट्रांज़ैक्शन अकेले चलने पर कंसिस्टेंसी डेटाबेस को सही रखती है।	प्रश्नपेढीनुसार, ट्रान्झॅक्शन एकटा चालताना कन्सिस्टन्सी डेटाबेस बरोबर ठेवते.
